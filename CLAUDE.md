# CLAUDE.md — Подхват AI+ (правила проекта)

Этот файл Claude Code читает автоматически в каждой сессии. Правила ниже действуют всегда, в любом промпте.

## Продукт
«Подхват AI+» — ИИ-администратор для частных стоматологий РФ. Перехватывает пропущенные звонки, возвращает пациентов через MAX/Telegram/SMS, показывает владельцу возвращённые рубли. Голос продукта — администратор «Анна». Пользователь: владелец клиники 35–55 лет, не технарь. Два его мотива: Покой (всё под контролем, данные в РФ) и Прибыль (рубли крупно).

## Железные правила (нарушение = брак)
1. **Дизайн-система `src/design/` — read-only.** Использовать её компоненты (`Button`, `Input`, `LeadCard`, `MoneyFigure`, `StatusBadge`, `Icon`, `BearMark`, блоки из `ui_kits/`), не переписывать и не дублировать стили.
2. **Цвета/шрифты/отступы — только CSS-переменные из `src/design/tokens/`.** Ни одного hex-кода вне токенов.
3. **Тексты интерфейса — по `src/design/DESIGN_README.md`:** словарь Анны («подхвачено», «возвращено 47 200 ₽», не «лид сконвертирован»), рубли с пробелами и ₽ после числа, минимальный кегль 16px, на «вы» со строчной, **без эмодзи в интерфейсе**.
4. **Безопасность-инварианты:** секреты только в `.env` (в git — `.env.example`); каждый запрос к данным фильтруется по `clinic_id`; входящие данные валидируются; персональные данные не покидают российский сервер (152-ФЗ); в логах и карточках — без медицинских диагнозов.
5. **Принцип «Правда требует доказательства»:** цифры вместо прилагательных, никаких сносок мелким шрифтом.

## Рабочий процесс
1. Сначала план файлов и список вопросов — код только после подтверждения владельца.
2. Реализация по фазам из промпта, после каждой фазы — короткий отчёт.
3. Перед сдачей — прогон приёмочных тестов/чек-листа Definition of Done из промпта.
4. Коммиты — семантические (`feat:`, `fix:`, `chore:`), после каждой завершённой фазы.
