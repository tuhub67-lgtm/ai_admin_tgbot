Карточка лида — главный компонент: пациент, услуга, время, канал (иконка), статус-бейдж, действия «Записан ✓ / Перезвонить / Потерян». Статус «urgent» включает фацетный маркер «Срочно — острая боль», тревожную рамку и кнопку «Перезвонить сейчас».

```jsx
<LeadCard name="Марина К." phone="+7 912 345-67-89" service="Острая боль" time="Сегодня 14:02"
  source="call" status="urgent" note="не дозвонилась, написала в MAX — жду ответа" />
<LeadCard name="Ольга В." phone="+7 921 555-01-77" service="Имплантация" time="Вчера 18:40"
  source="max" status="booked" sum={52000} />
```
