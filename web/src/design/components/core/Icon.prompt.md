Фирменная линейная иконка (24px, штрих 2px, гранёные углы в стиле логотипа-медведя); используй для каналов, статусов и навигации вместо любых сторонних сетов и эмодзи.

```jsx
<Icon name="call-missed" size={24} />
<Icon name="ruble" size={20} color="var(--text-gold)" />
```

Глифы: call, call-missed, patient, booking, ruble, report, settings, max, telegram, sms, shield, clock, urgent, check, dialog, return, bell, search. Каналы (max/telegram/sms) — нейтральные метафоры, не логотипы брендов.
