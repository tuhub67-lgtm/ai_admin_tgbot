# Дизайн-система «Подхват AI+»

ИИ-администратор для частных стоматологий. Перехватывает пропущенные звонки, возвращает пациентов через MAX / Telegram / SMS, показывает владельцу возвращённые рубли. Голос продукта — администратор «Анна».

**Пользователь:** владелец клиники 35–55 лет, не технарь, смотрит с телефона, ценит надёжность и деньги. Два скрытых мотива — **Покой** (ничего не потеряно, всё под контролем, данные в России) и **Прибыль** (рубли крупно, окупаемость видна).

**Источники:** утверждённый логотип — `assets/logo-source.png` (загружен владельцем, кропы: `assets/logo-tile-wine.png`, `assets/logo-tile-ivory.png`). Других источников (Figma, кодовая база) не было — система построена от логотипа и брифа.

## Принципы

### 1. Правда требует доказательства
Интерфейс говорит цифрами, а не прилагательными. Каждый экран отвечает на вопрос владельца «почему вы?» без слов.
- ✅ «Возвращено 47 200 ₽ за неделю»
- ❌ «Мы эффективно возвращаем пациентов»

### 2. Покой и Прибыль
Каждый экран обслуживает хотя бы один из двух мотивов: Покой (ничего не потеряно, данные в РФ) или Прибыль (рубли крупно, окупаемость видна).
- ✅ «Все 6 звонков подхвачены. Пилот окупился на 9-й день»
- ❌ Экран статистики звонков без сумм и без итога «всё под контролем»

### 3. Что, где, сколько — сразу
Главная цифра экрана видна за 1 секунду, крупным кеглем (стиль «Денежная цифра»). Никаких сносок мелким шрифтом, никаких «засад».
- ✅ 47 200 ₽ кеглем 72px, подпись 16px обычным цветом
- ❌ «Экономия до 50 000 ₽*» и сноска 10px внизу экрана

### 4. Дорого = сдержанно
Красный ≤20% поверхности, золото ≤8% (только акценты), остальное — нейтральные. Былинная сила — в геометрии и сдержанности, не в орнаменте.
- ✅ Белая карточка, одна золотая цифра, один винный бейдж
- ❌ Винная заливка всего экрана с золотыми рамками

### Запрещено
Лубок, хохлома, псевдославянская вязь, стоковые улыбки, градиенты-радуги, аляповатость, эмодзи в интерфейсе.

## CONTENT FUNDAMENTALS — как мы пишем

Тон — Анна: тепло, коротко, по делу. Обращение к владельцу на «вы» (со строчной). Без канцелярита, без англицизмов без нужды, без восклицательной экзальтации. Одно слово бренда — **«Подхватим»**.

### Мини-словарь
| Говорим | Не говорим |
|---|---|
| Подхвачено | Лид обработан |
| Возвращено 47 200 ₽ | Конверсия выросла |
| Пациент записан | Лид сконвертирован |
| Не дозвонились — Анна написала в MAX | Попытка контакта неуспешна |
| Что-то пошло не так, уже чиним | Ошибка 500 |
| Пропущенный звонок | Упущенный лид |
| Пилот окупился на 9-й день | ROI 340% |

### Правила цифр
- Рубли: `47 200 ₽` — пробел между тысячами, пробел перед ₽, знак после числа. Не «руб.», не «RUB».
- Денежные цифры — всегда табличные (`tnum`), шрифт Golos Text.
- Копейки не показываем. Округляем до рубля.
- Даты: «9-й день», «за неделю», «сегодня» — по-человечески, не «01.07.2026» в живом интерфейсе (в PDF-отчёте — можно период датами).
- Телефоны: `+7 912 345-67-89`.

### Примеры голоса Анны
- «Марина не дозвонилась в 14:02. Я написала ей в MAX — жду ответа.»
- «Записала Ольгу на чистку, четверг 16:00.»
- «Пока тихо. Все звонки подхвачены.»

## VISUAL FOUNDATIONS

**ДНК логотипа:** гранёная геометричная голова медведя. Фацетные углы (срезы 45°), две толщины линии, спокойная сила. Вся система наследует эту геометрию.

- **Цвет:** винный `#6F0D1E` (ступень 800 рампы) — брендовые поверхности, ≤20% экрана. Золото `#E7C258` (400) — CTA, подсветка «возвращено», ≤8%. Фон светлой темы — слоновая кость `#FCF2DC`, карточки белые. Тёмная тема — уголь `#1C1A17` с винными и золотыми акцентами. Тревожный оранжево-красный `#D9481F` — только «срочно/боль», не путать с брендовым винным. Полные рампы и контрастные пары — `design-tokens.json`, `tokens/colors.css`.
- **Типографика:** Golos Text (заголовки + все цифры; российская школа, гранёный характер — родня логотипу) + Inter (текст интерфейса). Минимальный кегль 16px (аудитория 45+), в PDF — 12pt. Стиль «Денежная цифра»: 72/44/28px, 700, tnum, знак ₽ встроен (чуть легче цифры).
- **Сетка:** 4pt. Поля 16 (моб.) / 24+ (десктоп), между карточками 12, внутри карточек 16–20.
- **Радиусы:** карточки 16 (малые 12), кнопки и поля 10, бейджи 8.
- **Фацет — фирменный приём:** один срезанный угол (обычно правый верхний), размеры 8/12/16/32. Где: бейдж «СРОЧНО», маркер записи, hero-блоки, шапка PDF. Не более одного фацетного элемента в поле зрения. Утилиты `.facet-*` в `tokens/spacing.css`.
- **Две толщины линии:** 1–1.5px структура (границы, разделители), 2px иконки, 4px акцентные планки.
- **Тени:** тёплые, мягкие, низкие (`--shadow-card`, `--shadow-raised`); «срочно» — с тёплым красным подтоном (`--shadow-urgent`). Без резких чёрных теней.
- **Ховеры:** сдвиг на ступень рампы темнее (`--cta-surface-hover`, `--surface-brand-hover`). Прессед — ещё ступень темнее. Без масштабирования и прыжков.
- **Движение:** 120/200/280ms, fade + сдвиг 4–8px. Денежная цифра может «набегать» счётчиком 600ms. Без пружин.
- **Фоны:** плоские заливки. Никаких градиентов. Изображения — только реальные (кабинет, команда), тёплая температура; пока их нет — полосатые плейсхолдеры с подписью.
- **Орнамент:** тонкий солярный медальон линией (`assets/ornament-solar.svg`) — ТОЛЬКО пустые состояния и обложки, прозрачность 4–6%. Никогда за текстом данных.
- **Фокус:** кольцо 2px золотом (`--focus-ring`), offset 2px.
- **Зоны нажатия:** ≥44px.

## ICONOGRAPHY

Свой линейный сет — `components/core/Icon.jsx` (18 глифов): 24px сетка, штрих 2px, квадратные окончания, miter-углы, гранёные срезы 45° в стиле логотипа. Каналы (MAX, Telegram, SMS) — нейтральные глифы-метафоры, НЕ логотипы этих брендов. Эмодзи и юникод-значки не используются. Статус-маркеры (ромб, точки, галочка, фацет, крест) встроены в `StatusBadge` — статус различим и без цвета.

## Индекс

- `design-tokens.json` — все токены (цвет обеих тем, типошкала, отступы, радиусы, фацет, тени, движение)
- `styles.css` → `tokens/` (colors, typography, spacing, effects)
- `assets/` — логотип (2 плашки), солярный орнамент
- `components/core/` — Icon
- `components/controls/` — Button, Input, Toggle
- `components/leads/` — StatusBadge, LeadCard (главный компонент системы)
- `components/money/` — MoneyFigure, RevenueBars
- `components/feedback/` — Toast, EmptyState, OnboardingStepper
- `components/data/` — DataTable, ReportHeader (шапка PDF)
- `ui_kits/app/` — мобильное приложение: лента, карточка лида, «Деньги», онбординг
- `ui_kits/landing/` — лендинг: hero с калькулятором потерь, доверие (152-ФЗ), тариф
- `ui_kits/social/` — посты 9:16 и 1:1, шапка PDF-отчёта
- `guidelines/` — спесимены основ, принципы, «Как НЕ надо»

**Интенциональные добавления** (источник — только логотип и бриф, компонентной базы не существовало): весь набор компонентов создан по брифу владельца; сет иконок нарисован специально под систему (в брифе заказан явно).
