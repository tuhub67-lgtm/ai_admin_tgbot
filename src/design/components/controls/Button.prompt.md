Кнопка «Подхват AI+»; primary (золото) — одно главное действие на экран, brand (винный) — рядом с брендовыми поверхностями, danger — только «срочно/боль».

```jsx
<Button icon="booking">Записан ✓</Button>
<Button variant="secondary" size="md">Перезвонить</Button>
<Button variant="danger" icon="urgent">Срочно — перезвонить</Button>
```

`forceState` — для витрин состояний. Текст кнопок — глаголами: «Подхватить», «Записан ✓», «Перезвонить».
