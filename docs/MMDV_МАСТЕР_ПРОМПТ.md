## Решения (приняты, не спрашивай)
- Язык — русский. Часовой пояс — МСК (хранение UTC, вывод МСК).
- Хостинг: сайт — Vercel; backend — Ubuntu VPS в РФ (docker compose + Caddy). Домен — плейсхолдер `PODHVAT_DOMAIN` в конфигах.
- Frontend: react-router-dom ставить можно; другие зависимости — только по явной необходимости, с обоснованием в плане.
- Backend: Python 3.12, FastAPI, aiogram 3, aiosqlite (SQLite сейчас, доступ через тонкий слой — переезд на Postgres позже).
- Биллинг в коде ОТСУТСТВУЕТ: оплата по счёту/СБП вне продукта, статус «оплачен» ставится вручную.
- Self-service регистрации НЕТ. Вход в кабинет — magic link через Telegram-бота (единственный канал в этой версии).
- Ручной режим записи по умолчанию: заявка `pending` → тап «Подтвердить» админом → финальное сообщение пациенту (идемпотентно).
- SMS — адаптер под SMS.ru, режим «мост» (первое сообщение + ссылка в мессенджер + «или перезвоним»).
- Форма заявки сайта: POST `backend /api/public/lead-request` (Этап B). До готовности backend — env `VITE_LEAD_WEBHOOK_URL`; если пуст — показать успех, залогировать в консоль, пометить TODO.
- Аналитика: Яндекс.Метрика через env `VITE_METRIKA_ID` (пусто — не подключать). Цели: отправка заявки, клик RuStore, клик «Войти».
- Демо-данные: клиника `demo-dent`, 8–10 лидов всех статусов (для скринов, тестов, демо-входа модератору).
- Тема: светлая по умолчанию, переключатель light/dark в кабинете (обе темы уже в токенах).
- Иконки — только из `src/design/components/core/Icon.jsx`; не хватает глифа — спроси.
- Бэкапы: cron-дамп SQLite в `/backups` ежедневно 03:00 + строка в деплой-доке, как раз в неделю забирать копию с VPS.
- Healthcheck: `GET /health` (БД доступна, версия) + строка в деплой-доке про мониторинг.
- Цены и тексты оффера: пилот 14 дней — 1 590 ₽ (перечёркнутое 4 900 ₽), подписка 14 900 ₽/мес; менять формулировки цен нельзя.
